# Changelog

All notable changes to the LoadAfrica project will be documented in this file.

---

## [1.0.0] - 2026-07-11

### Added
- **Transport Booking Engine (`CreateBooking.jsx`)**: Responsive step-by-step layout matching plant hire styling, with route maps and draft persistence.
- **Plant Hire Portal (`BookPlantMachine.jsx`)**: Booking interface for excavators/loaders with operator verification.
- **Broker Notification Bell (`BrokerLayout.jsx`)**: Add dynamic notification bell dropdown in broker layout linked to real-time custom event syncing.
- **Database System**: Prisma schema integration covering Shippers, Drivers, Fleet Owners, Hire Requests, and Invoices.
